## Research scope

The main comparison spans eight design families and includes three historical discontinuation cases. It is a structured comparative desk review, not an exhaustive census or a causal experiment across all games. Original-era claims, current documented mechanics, analytical interpretations, and proposed implementation choices are distinguished. Source records include developer documentation, original interviews, original code, research, official frameworks, and supplied Purpose Academy materials; they are not 93 independent scientific studies.

The original 2048 code was inspected for specific behavior. Other technical game models are clearly labeled clean-room abstractions. Private commercial algorithms and exact success probabilities are not invented. The recipe is a testable design process rather than a guarantee of a cultural or financial hit.

## Cursor use

Keep the files as plain UTF-8 text and structured JSON or CSV. Attach the Markdown brief and systems framework first, then the research report as reference. Ask Cursor to inspect the existing repository before proposing changes. The existing project stack was not inspected for this report.

Do not ask Cursor to implement every game pattern at once. Begin with one reviewed construction learning slice and preserve the distinction between activity, learning evidence, and human practical assessment. Logistics and Community Support require their own review before expansion.

## Draft fixture status

All three sample items are deliberately marked `draft`. Required image or audio assets remain missing in two examples, and approvals are absent throughout. They are structurally usable development fixtures, not publication-ready lessons. They must fail a production publication gate. No multilingual translations or safety qualifications are claimed.

The schema covers choice activities only and cannot express every application requirement. Semantic reference checks, actual asset inspection, task validity, content version coverage, accessibility review, translation review, and qualified domain review remain separate requirements.
