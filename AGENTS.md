# Agents — Purpose Academy

Before changing UI, curriculum packs, brand copy, learning flow, sound, or public trust pages:

1. Read **[`docs/CRAFTSMANSHIP.md`](docs/CRAFTSMANSHIP.md)** — living craftsmanship doctrine (incl. §7.1 composition + §7.2 motion).
2. Name which **craft layer(s)** you are touching (L1 truth, L2 content delivery, L3 aesthetic optics, L4 attention ethics, L5 trust, L6 systems spine).
3. For splash/opening work: apply composition (focal point, thirds, hierarchy, balance, framing) and motion foundations *before* site-wide chrome.
4. Apply the change **site-wide** for that layer when the climb is past splash lock — public, splash/enter, auth, Practice, School path, Learn.
5. Ask: does this pull people into mindless *more*, or walk them into a finished station?
6. When product truth or craft rules change, **update** `docs/CRAFTSMANSHIP.md` (changelog + climbs). It is not fixed.

Study: [Design Systems Repo](https://designsystemsrepo.com/) for later system discipline; Illusion of Life + screen motion translations for animation. Quality is a continuous journey.
