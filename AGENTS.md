# Agents — Purpose Academy

Before changing UI, curriculum packs, brand copy, learning flow, sound, or public trust pages:

1. Read **[`docs/CRAFTSMANSHIP.md`](docs/CRAFTSMANSHIP.md)** — living craftsmanship doctrine (§1 builder+critic, §3.1 systems, **§7.0–7.0b aesthetics + information display**, §7 composition/motion/door).
2. Read **[`docs/LEARNER_FEAR.md`](docs/LEARNER_FEAR.md)** — standing standard for adults who fear education. Ban exam/quiz/assessment/mastery/% theatre; prefer hear→hear→type reps and soft retries. Run its spine checklist on every Practice change.
3. Name which **craft layer(s)** you are touching (L1–L6).
4. **Be the critic of your own build** — relentless, never toxic. Customer first. Build → destroy → question → improve. No version is the final destination.
5. **Systems test:** excellent in isolation *and* continuous with neighbors (gateway → Home → path → Practice).
6. **Information display first (L3):** task, media, and result must be unmistakable in three seconds. Inherit §7 shared grammar — do not invent a one-off dialect. Whole-object photos (`contain`); visible success; one primary continue.
7. For splash/opening: composition + door architecture + motion first; then site-wide chrome.
8. Apply the change **site-wide** for that layer (marketing ↔ Practice ↔ portal ↔ Learn) — orphan surfaces fail the connection test.
9. Ask: does this pull someone into mindless *more*, or walk them into a finished station? Would a proud tradesperson feel small?
10. Run the **§7.0a pre-ship critic** and the **LEARNER_FEAR pre-ship critic** before merge on any UI/curriculum/Practice surface.
11. Update `docs/CRAFTSMANSHIP.md` and `docs/LEARNER_FEAR.md` when truth or craft rules change — including when the critic overturned a prior choice.
12. **Splash versions:** before overturning a loved composition, snapshot it (`node scripts/splash-version.mjs snapshot vN --note "..."`). Restore with `restore vN`. See [`docs/splash-versions/`](docs/splash-versions/).

Study: [Design Systems Repo](https://designsystemsrepo.com/); [awesome-system-design-resources](https://github.com/ashishps1/awesome-system-design-resources); Illusion of Life + perspective. Quality is a continuous journey. Solid user information output is of the utmost importance.
