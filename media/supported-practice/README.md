# Supported Practice videos (Video Match · Copycat)

Royalty-free **Mixkit** workplace clips, cut for Purpose Academy Level-4 sentence games.

## Edit standard

- Target ~3s · 1280×720 · H.264 · muted (Jenny VO lives in the app)
- Cut on the verb: start just before the key action, end after it resolves
- Soft fade in/out · light contrast/saturation · mild unsharp
- No watermarks · no mid-clip B-roll that strays from the sentence
