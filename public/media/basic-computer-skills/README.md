## How they were made

- **B-roll:** Mixkit free stock video from the Computer category + mouse/desk clips
  (Mixkit Stock Video Free License — commercial use).
- **Teaching layer:** Purpose Academy Level-4 English captions burned in with ffmpeg (ASS).
- **Rebuild:** download Mixkit computer clips into `/tmp/bcs-broll2` (and optional extras into
  `/tmp/bcs-broll`), then run `python3 scripts/build-basic-computer-skills-videos.py`.

## Pedagogy

Each lesson in the app: **Watch → Try → Remember → one check**.

Audience: learners who may never have used a computer; English at about Canadian Language Benchmark level 4.
